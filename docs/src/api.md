# C++ API Reference

The public C++ header reference is generated by Doxygen and published alongside
this book.

➡️ **[Open the C++ API reference](./api/index.html)**

It is built from the public headers of:

- `mfd_common_api/include`
- `mfd_api/include`
- `mfd_client_api/include`
- `mfd_runtime_api/include`
- `mfd_window/include`
- `mfd_window_plugin_api/include`

The Doxygen site is scoped to the C++ API surface only. For usage, authoring, and
integration guidance, stay in this book:

- [Generated Client API](./handbook/generated_api.md) — the preferred client surface
- [Offscreen Embedding](./handbook/offscreen.md) — `mfd_runtime_api`
- [Framebuffer Capture](./handbook/framebuffer.md) — `mfd_window_plugin_api`

> The `./api/` link resolves only on the published site or after a local build
> with `docs/BuildDocsSite.ps1`, which copies the Doxygen HTML into
> `build/docs/site/api`.
