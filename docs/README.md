# MFDStudio Documentation

Main documentation source:

- [`docs/src/`](./src/index.md)

Build local documentation:

```powershell
pwsh -File docs/BuildDocsSite.ps1 -Version local
```

Published site output:

- `build/docs/site`

API reference:

- generated by Doxygen into `build/docs/site/api`

Quality checks (broken links, missing images, absolute paths, orphan pages, and
an optional mdBook build):

```powershell
pwsh -File docs/CheckDocs.ps1
pwsh -File docs/CheckDocs.ps1 -SkipBuild   # static checks only, no mdBook needed
```
