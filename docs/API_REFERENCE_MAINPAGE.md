# MFDStudio API Reference

@tableofcontents

## Overview

This site is the generated Doxygen reference for the public C++ API shipped by
`MFDStudio`.

It focuses on the versioned API surface exposed from:

- `mfd_api/include`
- `client_api/include`
- `mfd_window/include`

The narrative onboarding, JSON authoring guides, and contributor workflows stay
in the repository Markdown documentation:

- [Project README](https://github.com/benoitfragit/MFDStudio/blob/main/README.md)
- [Documentation Guide](https://github.com/benoitfragit/MFDStudio/blob/main/docs/README.md)
- [Development Guide](https://github.com/benoitfragit/MFDStudio/blob/main/docs/DEVELOPMENT.md)

## What Is Published Here

- namespace, class, struct, function, and type alias reference for the public
  headers
- inheritance and dependency diagrams generated through Graphviz
- source browsing for the published headers

## Release Publishing

The repository publishes this API reference automatically to GitHub Pages each
time a GitHub release is published. The published site therefore tracks the
latest released API, not the latest unpublished commit on `main`.
